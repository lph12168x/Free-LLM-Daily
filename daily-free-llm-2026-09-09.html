🆕 蚂蚁开源 Ling-3.0-flash-VL：124B 只激活 5.5B 的原生多模态，Ling Studio 免费体验
蚂蚁集团今日（9/9）正式发布并开源百灵系列首个原生多模态模型 Ling-3.0-flash-VL， 基于 Ling-3.0-flash 的 MoE 架构扩展，总参 124B、单次推理仅激活 5.5B，原生支持图像 / 文本 / 视频输入，上下文 256K。
技术亮点引入视觉反馈闭环：把任务从「一次性看图生成」改造成「观察 → 行动 → 验证 → 修正」的持续循环。配任意分辨率视觉编码器与 VideoRoPE，语言主干是 42 层混合架构（KDA 与 Gated MLA 按 5:1 交替）。
跑分Artificial Analysis Intelligence Index v4.1.1 上比纯文本版 Ling-3.0-Flash +4 分；Image-to-WebDev Arena 官方评测（代号 linthium）得分高于 GPT-5.4。图转网页能看懂布局与组件关系，还能拿渲染结果对比自我修正。
怎么白嫖① Ling Studio 已上线并免费体验；② BF16 / FP8 权重已开源到 Hugging Face 与 ModelScope（FP4 / INT4 待发布），本地部署零成本；③ 医疗报告解读、前端代码生成、GUI 自动化是它的主场。
为什么值得关注Ling 系列的 inclusionai/ling-3.0-flash-fin:free 与 ling-3.0-flash-sante:free 目前正挂在 OpenRouter 免费池、ling-3.0-flash-fin-free 在 Zen 免费档。VL 版开源权重落地后，大概率会补齐到同一批免费通道。
⚠️ 目前「免费」指的是 Ling Studio 体验 + 开源权重自部署；API 免费档还要等上架。124B 的 BF16 权重本地跑需要多卡，FP4/INT4 发布后门槛会明显下降。
