DeepSeek V4 Pro 高峰：缓存命中输入 0.30 / 未命中 9 / 输出 27 元每百万 · 闲时半价 · 火山引擎协作计划每日 200 万 Token（含 V4 Pro）· Nous Portal 3 款免费模型、OpenAI 兼容、OAuth 登录

① DeepSeek 涨价到底涨多少（以官方价格页为准）：峰谷定价下，V4 Pro 高峰 缓存命中输入 0.30、缓存未命中输入 9、输出 27 元/百万；闲时 缓存命中 0.15、未命中 4.5、输出 13.5 元/百万（闲时为高峰的一半）。V4 Flash 高峰输出 9 元、闲时 4.5 元。涨价主因是调用量暴增——8 月 1 日 V4 Flash 单日处理 Token 达 8 万亿，中国日均 Token 调用量已破 140 万亿。对开发者而言，受冲击最大的是长上下文、高缓存复用的 Agent 用户（缓存命中输入涨幅最大）。⚠️ 但免费路径不受影响：NIM（88）/ OpenCode Zen（Free）/ 火山引擎（新 200 万/天含 V4 Pro）三条通道照旧。

② 火山引擎新羊毛：每日 200 万 Token（含 V4 Pro）：加入火山引擎「大模型协作计划」后，每天自动重置 200 万 Token 免费调用额度（含 Prompt 输入与 Output 生成），背靠火山庞大算力池、并发强。⚠️ 关键陷阱：该额度没有开关——必须在代码端手动维护全局 Token 计数器，当日累计达 190 万时触发 sys.exit() 断路，并设置账户余额预警与单次任务最大递归深度，防 Agent 死循环连夜烧钱。这是今天最值得薅、也最需要设防的免费额度。

③ Nous Portal 免费层上线（用户点名关注的「nous」）：Nous Research 的模型网关提供 3 款完全免费模型——Step-3.7-Flash、Nemotron-3-Ultra、Owl-Alpha，标准 OpenAI 兼容 API（Base URL https://inference-api.nousresearch.com/v1），OAuth 设备码流程登录，聚合 266+ 开源模型。这是今天新增的「量大能用」免费入口之一，适合接 Hermes Agent / Trae / Continue / Cline / Aider 等工具。⚠️ 免费额度以官网当前政策为准，部分模型可能限流。

④ 同期补充：OpenCode Zen 的 DeepSeek V4 Flash Free（1M / 384K 输出）仍在限时免费；OpenRouter 免费层 25+ 模型（含 Nemotron 3 Ultra、Gemma 4 31B/26B、North Mini Code、Ling-3.0-flash、Nemotron 3.5 Lightning、GPT-OSS-20B）；「command code」应为 Cohere Command 系列（Command R / R7B）——其免费层经 Cohere 官方（20 req/min、1000 req/month，含 Command R7B）或 OpenRouter 的 north-mini-code:free 可用（未找到名为「command code」的独立免费 LLM API 提供商，此处为推断）。
