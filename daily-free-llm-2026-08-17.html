今日头号（对「免费」最有实操价值）：8/14 晚，阿里千问正式开源 Qwen3.8-27B——27B 参数的原生多模态稠密（Dense）模型，以最宽松的 Apache 2.0 协议开放权重，所有人可免费下载、部署、商用。它支持 262K 原生上下文、YaRN 可外推至 1M，新增 reasoning_effort 动态调节思考深度；据官方基准，Agentic terminal coding 73.0（Qwen3.6-27B 为 63.4）、SWE-bench Pro 61.7（53.5）、JobBench 33.4（21.8，提升约 50%），编程 / 办公场景已超 Qwen3.6-27B、甚至优于 Qwen3.7-Plus。最关键的是门槛：4-bit 量化约 17GB，24GB 显卡或 32GB Mac / 迷你主机即可本地跑，llama.cpp 首日即支持，Hugging Face 与 ModelScope 同步上线——这是目前对个人开发者最友好的「先进模型零成本本地部署」选择。

① Qwen3.8-27B：把「前沿多模态」压进消费级硬件：Qwen 团队于 8/14 开源的 27B 是原生视觉语言模型（不是后期拼接视觉编码器，而是从头联合训练），图文视频全理解；262K 原生上下文、YaRN 扩至 1M，默认开启思维链并支持 reasoning_effort 调节。性能上，编程（Agentic terminal coding 73.0 / SWE-bench Pro 61.7）与办公（JobBench 33.4）较前代大幅提升，官方称整体优于 Qwen3.7-Plus。部署门槛极具亲和力：Unsloth 动态 4-bit 约 17GB，24GB 显卡或 32GB 统一内存 Mac / 迷你 PC 即可流畅运行，llama.cpp 首日支持。Apache 2.0 意味着完全商用自由、无收入阈值限制——与需要商业协议的 Max 形成鲜明对比。截至今日，千问已累计开源 460+ 模型、全球下载超 30 亿次。

② OpenCode Zen：编码 Agent 场景的开箱即用免费层：OpenCode 官方维护的模型网关 Zen，登录（GitHub / Google 快速登录）免信用卡即领 API Key，完全 OpenAI 兼容（Base URL https://opencode.ai/zen/v1）。其中带 「Free」标签的模型限时免费，当前含 DeepSeek V4 Flash Free（1M 上下文 / 384K 输出、工具调用、JSON 模式）、MiniMax M2.5 Free、Nemotron 3 Ultra Free、Big Pickle、MiMo-V2.5 Free、North Mini Code Free、Hy3 preview 等。Zen 的模型经过官方「测试与验证」，主打在编码 Agent 场景少踩兼容性与工具调用坑——把它填进任何支持 OpenAI API 的工具（Cursor / 自写脚本 / 自建 Agent）即可免费调用。⚠️ 注意：Free 模型为限时免费，且数据可能用于改进模型，敏感 / 客户数据勿走免费档；早前的 qwen3.6-plus-free 活动已结束，用前请先 opencode models 看当前可用。

③ 但要分清「开源」与「免费 API」：Qwen3.8-27B 的零成本 = 本地部署（有 24GB 显卡 / 32GB Mac 即可）；Zen 的零成本 = 限时免费云调用（无需自建算力）。两者都不依赖付费 API Key，是今天新增的两条最干净、最普适的零成本路径。而像 GLM-5.2 / DeepSeek V4 Flash 这类，则是「云厂商常驻免费层」路线（NVIDIA NIM 40 RPM 无日限额）——三种路线各取所需。
