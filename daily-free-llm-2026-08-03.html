今日头号（对「免费」最有实操价值）：过去一周我们反复追问的问题是「K3 开源了，但普通人到底怎么零成本用上它」。7/31 的答案是阿里云百炼新人额度，而这个周末出现了更直接的一条路——freellm.net 8/2 刷新的实测目录里，kimi-k3 以 98 分空降全部免费模型第一名，供应商是 Ollama Cloud，标记为「Free tier / Verified」。这意味着只要注册一个 Ollama 账号（官方明确写着「Cloud models included free with an Ollama account」），就能用 OpenAI 兼容格式的 https://api.ollama.com 调用这颗 2.8 万亿参数的模型，128K 上下文、支持文本 / 图像 / 视频输入、推理与工具调用全开。GLM-5.2 自 6 月中旬以来连续霸榜一个半月的免费第一，今天正式易主（它仍以 95 分稳居第二，且 NVIDIA NIM 侧周调用量高达 3.0T，是可用性最稳的一档）。

周末第二条主线：DeepSeek 于 7/31 开源 V4-Flash 0731 版——284B 总参 / 13B 激活、MIT 许可、FP4/FP8 混合精度约 167GB，Artificial Analysis 智能指数 50 分位列开源模型前三；官方 API 同步公测上线，Agent 能力基准分数大幅超越 V4-Pro-Preview，并原生支持 Responses API 格式、已完全适配 Codex。它在 freellm.net 上同时出现在 Ollama Cloud（90 分，1M 上下文）与 NVIDIA NIM（88 分）两个免费入口，直接顶进免费榜第 4。

周末第三条主线：8/2 月之暗面把 K3 的全套底层框架也开源了——训练引擎 MoonTrain、微调工具集 MoonTune、智能体框架 MoonAgent，全部 Apache 2.0。开源的重心正从「给模型权重」转向「连灶台和火候表一起给」。同期 MiniMax 发布多模态生成模型 H3（2K 分辨率 / 15 秒带原生立体声、AA 视频编辑榜全球第一、0.8 元/秒约为同类三分之一，官方称近日开源），阿布扎比 TII 发布 Falcon H1R 7B（Mamba + Transformer 混合头，以 7B 挑战 14B/32B/47B）。

今日必须今天做的一件事：蚂蚁百灵 Ling-3.0-flash 的限时免费 API 今晚 23:00（北京时间）准点关闭。这颗 7/24 发布的模型总参 124B、单 Token 仅激活 5.1B，却在 34 个评测维度拿下 15 个第一、19 个第二，综合均分与 DeepSeek-V4-Flash 并列第一，领先自家万亿旗舰 Ring-2.6-1T（59.7 分）近 8 分，SWE-Bench Pro 56.6% 为参测模型第一；原生 256K 上下文、最高可扩至 1M，支持思考 / 非思考双模式。发布 5 天内它在 OpenRouter 的 Token 调用量就从第 9 冲到第 6，7/29 单日调用量仅比 DeepSeek V4-Pro 低 0.5%——这是本周被低估得最厉害的一档免费额度。免费期结束后官方将正式开源权重，所以今天该做两件事：白天把要跑的评测 / 对比一次性跑完，之后转为等权重开源本地部署。

从「下载得到、跑不起」到「注册就能调」：K3 的免费之路终于走通

Ollama Cloud 免费层上架 kimi-k3（98 分 · 128K · 文/图/视频输入）· DeepSeek V4-Flash 0731 MIT 开源并进 AA 开源前三 · MoonTrain / MoonTune / MoonAgent 全栈框架 Apache 2.0 开源

① 换王的实际含义：K3 在 7/27 全量开源后，卡在一个尴尬处——权重可下载，但要 8×H100 起步，个人开发者只能远观。7/31 阿里云百炼上线 K3 官方 API + 新人每模型 100 万 Token，补上了第一条缝；这个周末 Ollama Cloud 把它放进了免费层，补上了第二条、也是门槛更低的一条：不需要国内云厂商账号、不需要申请额度，注册即用，OpenAI 兼容。freellm.net 的实测评分给到 98 分（Intelligence 57.1 / Coding 76.2 / Agentic 50.1，观测生成速度约 35 tok/s），是该目录追踪的 424 款免费模型里的最高分。

② 但这个「免费」有明确的边界：Ollama 免费档的官方表述是「Light usage」，采用每 5 小时重置的会话额度 + 每 7 天重置的周额度，且按 GPU 时间而非固定 token 数计量——具体数值官方并未公开，freellm.net 也如实标注为「Session/weekly limits (unpublished)」。更值得注意的信号是：Ollama 官方在定价页写明，因为云端 token 量每月翻倍、加上 kimi-k3 这类超大模型上线，Max 订阅已暂停新注册。换句话说，这是一条真实但不保量的通道，适合评估、演示和轻量生产，重度调用仍需回落到 NVIDIA NIM（约 40 RPM、无固定日额度）或国内云厂商额度。

③ DeepSeek 的周末动作同样关键：7/31 开源的 DeepSeek V4-Flash 0731 采用 MIT 许可，284B 总参 / 13B 激活，与原 V4-Flash 架构和定价一致，AA 智能指数 50 分入围开源前三。官方 API 已开公测，主打 Agent 能力跃升，并原生支持 Responses API、完成 Codex 适配——对做编码 Agent 的人来说，这是继 GLM-5.2 之后又一个「免费入口 + 开源权重 + 官方工具链适配」三者齐备的选项。它在 Ollama Cloud（90 分 / 1M 上下文）和 NVIDIA NIM（88 分 / 393K 输出）双双上架免费层。

④ 开源范式在升级：8/2 月之暗面开源 K3 背后的三件套——MoonTrain（含 MuonClip 优化器实现、混合精度与张量并行、通用 RL 管线、数据飞轮编排）、MoonTune（SFT / DPO / 领域适配 + LLM 裁判数据闭环）、MoonAgent（工具调用编排、长上下文持久化、多轮规划与反思），均为 Apache 2.0。此前社区只能从技术报告里读到 MuonClip 如何稳住万亿参数训练，现在可以直接拿到能跑的引擎代码。叠加 7/31 国家发改委发布会确认的「上半年国产大模型全球下载量突破 100 亿次」，以及美团 LongCat-2.0（1.6T、首个全流程国产算力训练的万亿模型）与 CatPaw 平台的推出，「模型开源 → 全栈工具链开源」这一步已经迈出去了。
