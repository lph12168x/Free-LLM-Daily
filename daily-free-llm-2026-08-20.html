④ 策略：重度编码期直接开 Comate 测试版把高级模型（Ernie 4.5T / X1T）免费用满；日常零成本对话 / API 仍用 GLM-5.2（NIM）/ kimi.com（K3）/ Gemini Flash / DeepSeek V4-Flash。三条线互补，月度成本仍可压到 ¥0。
