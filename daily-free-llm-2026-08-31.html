腾讯 Hy4 Preview 开源：770B 参数、1M 上下文，官方客户端免费两周

腾讯 · 770B 总参 / 49B 激活 · 1M 上下文 · HF 权重 1.56TB · 纯文本（无视觉）· WorkBuddy/CodeBuddy 免费两周

① 发生了什么：腾讯在 8 月 29 日发布并开源下一代大语言模型 Tencent Hy4 Preview， 总参数 770B、激活参数 49B、上下文窗口超过 1M tokens，Hugging Face 上权重体积 1.56TB。 对比 7 月的 Hy3（295B 总参 / 21B 激活 / 256K / 598GB），这是一次全面放大。腾讯定位为「编程、办公、科研等真实生产力任务」。

② 关键能力（看清楚）：内部盲评 163 位专家 × 203 项工程任务，Hy4 preview 平均 2.99/4.00， 略高于 Kimi K3（2.94）与 GLM-5.3（2.92）。推理配置只支持 high（默认）与 no_think 两档， 没有 low/medium。纯文本输入，无视觉能力——这条很关键，读图读视频请另找模型。 有意思的细节：Simon Willison 实测发现它「思考」时用破碎的、半语法的英文写内部笔记 （比如纠结要不要给鹈鹕加头盔，最后因为喙会挡住而放弃）——说明隐藏推理是为压缩效率服务的，不是为人类可读服务的。

③ 免费怎么用：WorkBuddy / CodeBuddy 里直接选 Hy4 preview，免费试用两周； 元宝、ima 同步上线。API 走腾讯云 TokenHub 与 OpenRouter——但这两条按量计费，免费额度只在 Buddy 客户端内。 1.56TB 权重自部署不现实，所以客户端是唯一现实的白嫖路径。

④ 策略：把长文档分析、代码库整体理解、批量报告生成这类重活压到这两周窗口里跑完。 同窗口内的 Hy3（295B / 256K / 快慢思考融合）也别浪费——两者叠加，腾讯系这两个月的免费额度相当可观。

🔥 权重落地 · 智谱 GLM-5.3（753B）正式开源：Intelligence 60 并列 Kimi K3，License 从 MIT 换成自定义协议

GLM-5.3 权重落地：FP8 主仓 756GB，只卡百亿美元巨头，个人开发者等同 MIT

智谱 Z.ai · 753B 总参 / 40B 激活 · 1M 上下文 · FP8 756GB（141 分片）+ BF16 另仓 · GLM-5.3 License

① 发生了什么：8 月 29 日凌晨，智谱（Z.ai）在 Hugging Face 与 ModelScope 放出 GLM-5.3 权重， 兑现了「安全评估完成后开放」的承诺。模型沿用 GLM-5.2 的基座，能力提升全部来自后训练—— 不是万亿参数，万亿大概率留给 GLM-5.5。官方称因「网络安全能力增长超出预期」而多做了两周安全评估。

② 关键指标：见下方对比表。最亮眼的是 CyberGym 84.5%，以及实测扫描 269 个开源项目、 累计 2436 个漏洞（其中 Linux / WebKit / FreeBSD 内核关键漏洞 1097 个）。 Terminal-Bench 3.0 从 GLM-5.2 的 4.6 直接跳到 28.3，DeepSWE v1.1 从 46.2 到 66.9。 chat template 从 5.08KB 涨到 10.5KB，新增代码集中在工具结果处理（识别 tool_call_id、去重补缺、 按原调用顺序重排异步返回的 Tool Results）——对写 Agent 工作流比跑分更实在。

③ License 变化（务必看）：GLM-5.2 用 MIT，GLM-5.3 换成自定义 GLM-5.3 License。 核心条款：企业及其关联方若经营 MaaS，且连续 12 个月合计营收 > 100 亿美元，商业使用前须先通过智谱安全审查。 实际只影响微软、Google、NVIDIA、阿里、腾讯这一档；个人开发者、创业公司、绝大多数企业仍是 MIT 式自由 ——免费使用、复制、修改、分发、再许可、销售、部署、微调、商用全部允许。 顺带一提：许可证没有 acceptable-use 条款，也没提网络安全限制，「安全」更像延后放权重的理由而非协议约束。 想要更干净的协议，Qwen3.8-Flash-Next 是 Apache 2.0，无任何营收门槛。

④ 免费怎么用：权重自部署永久免费（vLLM / SGLang / KTransformers / Transformers 均已支持， 海光 DCU 已 Day 0 适配）。Unsloth 量化版 UD-IQ2_M 可在 24GB 显存 + 256GB 内存的机器上跑， 社区另有 239GB 2-bit 量化（据说保留约 81% 精度）。官方把 FP8 作为主仓默认—— 对比 GLM-5.2 主仓 BF16 超 1TB，开箱门槛明显更低。NIM 免费层的 GLM-5.3 还在路上， 过渡期继续用 GLM-5.2（NIM 93-94、1M、40 RPM 无日限额、永久免费）。

隐身模型 = 数据诱饵：OpenRouter 只承诺「不训练」，没承诺「不保留」

Ox Alpha 那轮留下的最大教训：OpenRouter 模型页写的是「provider does not train on your prompts or completions」， 但保留（retention）与训练（training）是两个独立承诺，只有一个被豁免。同期 OpenCode 宣传的「零数据保留」说的是它客户端这一层， 盖不到匿名供应商那一层。隐身模型本质上是厂商收集反馈的诱饵，窗口一过就撤—— 别把生产密钥、客户数据、NDA 内容送进匿名端点。

License 不等于 MIT：GLM-5.3 换成自定义协议，Qwen3.8-Flash-Next 才是干净的 Apache 2.0

GLM-5.3 从 MIT 换成 GLM-5.3 License：做 MaaS 且连续 12 个月营收 > 100 亿美元的主体，商业使用前须过智谱安全审查。 个人开发者与创业公司等同 MIT，但若你所在主体接近这条线，务必先过法务。 横向对比：Moonshot 对 Kimi K3 要求「月活 >1 亿或月营收 >$2000 万须显著标注」，DeepSeek 仍是纯 MIT， Qwen3.8-Flash-Next 是 Apache 2.0、零营收门槛。另外 GLM-5.3 许可证没有 acceptable-use 条款， 「安全」更像延后放权重的理由而非协议约束。
