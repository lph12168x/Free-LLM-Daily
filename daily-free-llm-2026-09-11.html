🆕 DeepSeek V4.1 Flash 权重开源落地，HuggingChat 已免费可聊：MIT 协议，零部署白嫖旗舰
昨天（9/10）刚发的 V4.1 Flash，今天权重已经悄悄挂上 Hugging Face，并且直接进 HuggingChat——有 HF 账号就能免费用，不用本地部署、不用 API Key。 这是本周「量大能用」最实在的一条：552B 参数的旗舰级 MoE，白嫖门槛被压到一个网页对话框。
架构与规格全新 Causal Encoder-Decoder：20 层因果编码器 + 20 层解码器，552B 主干 + 196B Engram 条件记忆，384 路由专家 + 1 共享专家、每 token 激活 6 个；prefill 仅激活 8B、decode 激活 16B；原生多模态视觉理解，1M 上下文。
真正的杀招FP4 KV cache + CSA2 稀疏注意力，把全局 KV cache 压到每 token 890 字节——约 V4-Flash 的 1/4、初代 V1 的 1/437；HBM 与 SSD 占用分别降到上一代的 1/4 和 1/8。完整 1M 上下文的缓存不到 1GB，长上下文 Agent 的成本结构被改写。
跑分GPQA Diamond 90.9、Codeforces Rating 3471、Terminal-Bench 2.1 90.6、DeepSWE v1.1 74.2——官方口径为性能 / 费用 / 速度 / 总用时全面超越 V4 Pro，且在 Agentic 榜上压过 GLM-5.3、Kimi K3。
零成本路径① HuggingChat 网页直接聊（零门槛，本期新增）；② OpenCode Zen 的 deepseek-v4-flash-free（20 RPM / 200 RPD）；③ NVIDIA NIM 的 deepseek-ai/deepseek-v4-flash-0731（免费、1.3M、40 RPM）；④ Ollama Cloud 免费档；⑤ chat.deepseek.com 网页端免费无公开上限；⑥ 权重自部署（MIT，可商用）。
生态跟进硅基流动 Day 0 上线；WorkBuddy / CodeBuddy / OpenCode 作为官方合作伙伴全量接入（WorkBuddy 赠两周免费试用）；DeepSeek 同时开源 deepseek-recipe、DeepSelect（TopK 内核比 torch.topk 快 2–20 倍）、DeepJIT（CUDA / 昇腾 JIT 运行时）三个部署仓库。

💰 Nebius 免费 AI Builder Program 上线：$400+ 额度横跨六层栈，含 NVIDIA / Qwen / MiniMax
Nebius（原 Yandex 拆分出来的 AI 云，阿姆斯特丹）9/10 宣布推出 完全免费的 AI Builder Program——不是「新用户试用金」，而是面向开发者的常设社区计划。 对「量大能用」的人来说，这是近期额度最厚的一次免费发放：它不是给单一模型的 token，而是把一整条开源 AI 技术栈的额度打包给你。
